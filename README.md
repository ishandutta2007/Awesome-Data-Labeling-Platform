# Awesome-Data-Labeling-Platform

## Top Data Labeling Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Annotation, Labeling Workflows, Human-in-the-Loop, Model-Assisted Labeling & Training Data Quality*

**Last updated: October 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Data Labeling**. These systems help teams annotate images, video, text, audio, and multimodal data to create high-quality training sets for machine learning models.



**Examples** include Labelbox, Scale AI, Label Studio, SuperAnnotate, CVAT, Lightly, V7, Prodigy, Kili Technology, Superb AI, Encord, Dataloop, Hasty.ai, Keymakr, Label Studio Enterprise, Snorkel Flow, BasicAI, V7 Labs, and Snorkel AI (the category leaders).



**Open-source emphasis**: Data labeling has excellent open-source options. **Label Studio**, **CVAT**, and **Doccano** are production-capable for many teams. This section is heavily expanded.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Labelbox](https://labelbox.com/)**  

  Enterprise data labeling and training-data platform with model-assisted labeling, quality workflows, and MLOps integrations.



- **[Scale AI](https://scale.com/)**  

  Leading managed labeling platform combining software with a large human workforce for high-quality, complex annotation at scale.



- **[Label Studio (Enterprise / HumanSignal)](https://labelstud.io/)**  

  Commercial offerings and enterprise features built on the open-source Label Studio annotation platform.



- **[SuperAnnotate](https://www.superannotate.com/)**  

  Annotation platform for images, video, and multimodal data with collaboration and quality management.



- **[CVAT (Enterprise / commercial support)](https://www.cvat.ai/)**  

  Commercial support and hosted options around the open-source Computer Vision Annotation Tool.



- **[Lightly](https://www.lightly.ai/)**  

  Data curation and active learning platform that reduces labeling volume by selecting the most valuable samples.



- **[V7 / V7 Labs](https://www.v7labs.com/)**  

  AI data engine for labeling images, video, and documents with automation and quality tools.



- **[Prodigy](https://prodi.gy/)**  

  Scriptable annotation tool focused on efficient, developer-centric labeling workflows (spaCy ecosystem).



- **[Kili Technology](https://kili-technology.com/)**  

  Labeling platform for training data with project management, quality control, and multi-data-type support.



- **[Superb AI](https://www.superb-ai.com/)**  

  Data ops and labeling platform oriented toward computer vision and ML teams.



- **[Encord](https://encord.com/)**  

  Annotation and data development platform strong on video, medical imaging, and multimodal quality workflows.



- **[Dataloop](https://dataloop.ai/)**  

  End-to-end data management and labeling platform for AI pipelines.



- **[Hasty.ai](https://www.hasty.ai/)**  

  AI-assisted annotation platform focused on accelerating computer vision labeling.



- **[Keymakr](https://keymakr.com/)**  

  Data annotation services and platform for high-quality labeled datasets.



- **[Snorkel Flow / Snorkel AI](https://snorkel.ai/)**  

  Programmatic labeling and data-centric AI platform for building and iterating training data with weak supervision.



- **[BasicAI](https://www.basic.ai/)**  

  Data labeling and annotation platform for computer vision and related ML tasks.



## Open-Source GitHub Projects

- **[Label Studio](https://github.com/HumanSignal/label-studio)**  

  Leading open-source multi-type data labeling tool for images, text, audio, video, time series, and more—highly configurable and self-hostable.



- **[CVAT](https://github.com/cvat-ai/cvat)**  

  Open-source Computer Vision Annotation Tool for images, video, and 3D—widely used for bounding boxes, polygons, and video tracking.



- **[Doccano](https://github.com/doccano/doccano)**  

  Open-source text annotation tool for classification, sequence labeling, and sequence-to-sequence tasks.



- **[Label Studio community templates & ML backends](https://github.com/HumanSignal)**  

  Extensions for model-assisted labeling and custom interfaces on top of Label Studio.



- **[CVAT AI / auto-annotation plugins](https://github.com/cvat-ai)**  

  Open components for integrating models into CVAT labeling workflows.



- **[Universal Data Tool / related open annotators](https://github.com/)**  

  Community annotation UIs for various data types and simple self-hosted setups.



- **[Active learning open libraries](https://github.com/)**  

  Tools that select high-value samples for labeling (complementary to Lightly-style workflows).



- **[Export format converters](https://github.com/)**  

  Open utilities for converting annotations between COCO, YOLO, VOC, Label Studio JSON, and other formats.



- **[Documentation and Label Studio / CVAT playbooks](https://labelstud.io/guide/)**  

  Guides for self-hosting, scaling annotator teams, and integrating with ML training pipelines.



- **[Self-hosted labeling stacks](https://github.com/)**  

  Patterns combining Label Studio or CVAT with object storage, auth, and model-assisted backends.



### Additional Strong Open-Source Options

- Using **Label Studio** for multimodal and LLM evaluation labeling.

- Choosing **CVAT** for computer vision (images, video, 3D).

- Using **Doccano** for focused NLP annotation projects.

- Accepting that managed workforces, enterprise QA at extreme scale, RLHF pipelines, and turnkey multi-tenant platforms still favor commercial vendors (Scale AI, Labelbox, Encord, SuperAnnotate, Snorkel, etc.).

- Focusing open-source efforts on data ownership, cost control, and custom labeling interfaces.



**Frameworks for building custom systems**: Deploy Label Studio or CVAT → integrate model-assisted pre-labels → manage projects and QA in the tool → export to training formats. Suitable for ML teams with internal annotators. High-volume or highly specialized labeling often uses commercial platforms or hybrid managed services.
